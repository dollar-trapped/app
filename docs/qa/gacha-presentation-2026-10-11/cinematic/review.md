# 도입부 영상 검토

2026-10-11, ffmpeg-analyse-video 스킬을 사용해 `intro.mp4`의 0.0~2.0초를 0.2초 간격으로 총 11프레임 추출·검토했다. 두 분석 담당이 이미지 구간을 읽고, 보고서와 구현 코드를 대조했다.

영상은 실제 Flutter painter를 출력한 420×900, H.264, 30fps, 2.033초 자료다. 실기기 촬영이 아니며 HUD·오디오·금고 개방 이후는 포함하지 않는다. 프레임 사이의 미세한 움직임, 소리와 진동의 동기화, 실기기 성능은 이 검토로 판단하지 않는다.

| 구간 | 관찰 | 시각적 판단 |
|---|---|---|
| 0.0~0.2초 | 희미한 구름과 작은 별, 아래쪽의 넓은 빈 그라데이션 | 도입의 시선 집중과 공간 설명이 약하다. |
| 0.4~0.8초 | 작은 선두 별의 이동이 적고, 뒤의 별은 규칙적인 열을 유지한다. | 낙하보다 UI 파티클 이동처럼 보인다. |
| 1.0~1.4초 | 꼬리와 속도선이 길어지지만 별의 크기 변화는 작다. | 접근 원근감이 약하고 마지막에 떠 있는 느낌을 준다. |
| 1.6초 | 별은 약 (252,422), 큰 금고는 약 (210,550)에 동시에 보인다. | 별과 금고 사이의 위치·크기 연결이 끊긴다. |
| 1.8~2.0초 | 하늘과 별이 사라지고 금고가 어두운 배경에 정착한다. 접촉 지점·충격 결과가 보이지 않는다. | 착지보다 별개 장면의 크로스페이드로 읽힌다. |

현재 영상은 완성된 시네마틱 착지라고 평가하기 어렵다. 금고 자산은 형태가 잘 읽히지만, 도입부의 공간과 동작 연결이 부족하다. 이는 시각적 평가이며 사용자 조사 결과가 아니다.

## 수정 우선순위

1. 별의 도착 지점과 금고 등장 지점을 하나로 연결한다.
2. 별이 해당 지점에 도달하기 전에는 금고가 따로 나타나지 않도록 한다. 구름 통과 또는 짧은 접촉광으로 의도적인 전환을 만든다.
3. 바닥·접촉 그림자와 짧은 충격 후 정착 동작으로 도착을 설명한다.
4. 초반 정체를 줄이고 별의 크기·원근 변화와 가까운 구름 가림을 강화한다.
5. 뒤따르는 별의 규칙적인 격자 배치를 완화한다.

반짝임과 속도선의 양만 늘리는 수정은 핵심 문제를 해결하지 못한다. 이번 검토에서는 제품 코드를 변경하지 않았다.
