# 하강 카메라·보상별 빛 수정

2026-10-12.

- 하늘과 지면을 한 화면에 맞추던 구도를 제거했다. 약 3개 화면 높이의 월드에서 낙하가 가속되고 카메라가 아래로 추적한다. 지면은 착지 직전에 화면 아래에서 들어온다.
- 각 보상의 빛·꼬리·파티클은 해당 보상의 등급 색이다. COMMON 초록, RARE 파랑을 유지하며 SPECIAL만 1.75초에 금색으로 반전한다. 공통 연출 시간과 충돌 강도에만 최고 등급을 사용한다.
- 기존 Blender 케이스를 유지한다. SPECIAL은 1.96–2.2초에 빛이 케이스로 모이고 2.55초에 직접 착지한다. 충돌 후 재질이 즉시 보이며 연기가 장시간 케이스를 가리지 않는다.
- 전체 Flutter 테스트 276개, 변경 영역 정적 검사 통과. 실제 Canvas 픽셀로 혼합 배치의 초록·파랑·금색이 동시에 남는 것, SPECIAL 반전 전 RARE와 동일한 렌더 결과를 확인했다.
- 카메라 초기 위치·가속·지면의 화면 밖 위치·착지 구도 고정, 빛 1/10개, 스킵 결과와 보상 순서, 이미지 해제를 검사했다.

## 검증 범위

이미지와 시연 영상은 실제 Flutter production 위젯·painter를 420×900으로 출력한 검토 자료다. 실기기 촬영이나 성능 측정 자료가 아니다.

USB 연결이 끊겨 이번 카메라 변경 후 실기기 측정과 최신 APK 설치는 진행하지 못했다. 앞선 `restored/profile.json`은 카메라 변경 이전 결과이므로 이번 버전의 성능 근거로 사용하지 않는다.

미리보기 APK는 `build/gacha-preview/gacha-preview-1.0.4-12.apk`이며 서버·로그인·실제 뽑기권 없이 실행한다.

## 속도 미세 조정

2026-10-12 후속 피드백: 도입·낙하·케이스 개방을 약 20% 늘렸다. SPECIAL 착지는 2.55→3.07초, 개방 완료는 3.95→4.75초다. 가속 곡선·개별 보상 색상은 유지하며, 카드별 공개 시간과 70ms 반전 섬광·hit-stop은 늘리지 않았다. 케이스 형성은 240→290ms다.

[조금 느리게 조정한 최신 시연](../../../../local-archive/gacha-videos/qa/gacha-presentation-2026-10-11/tracking/special_10_slower.mp4). 뽑기·배치·순차 공개·수명주기·픽셀 검증 및 영상 생성 관련 24개 테스트 통과. USB 미연결로 이번 수정본은 폰에 설치하지 못했다. 위의 276개 전체 테스트는 속도 조정 전 기록이다.

## 하늘 낙하 구간 추가 연장

2026-10-12 후속 피드백: 하늘 낙하만 COMMON 1.2→1.8초, RARE/SPECIAL 2.1→3.1초로 늘렸다. 정적·충돌·개방·카드 공개의 구간 길이는 직전 버전과 같다. SPECIAL 반전은 2.85초로 옮겨 낙하 후반에 유지했다. 실제 추첨 결과와 개별 빛의 색은 변경하지 않았다.

[하늘 낙하가 길어진 최신 시연](../../../../local-archive/gacha-videos/qa/gacha-presentation-2026-10-11/tracking/special_10_long_sky.mp4). 관련 24개 테스트 및 정적 검사 통과. 실제 Flutter 렌더를 15fps로 출력한 시연 자료이며 실기기 성능 측정은 아니다.

## 합체·변신 제거, 뚜껑 위 개별 충돌

2026-10-12 후속 피드백: 빛이 한 점에 모이며 케이스로 변하는 전환을 제거했다. Blender 케이스는 처음부터 지면의 고정 위치에 있고 카메라 하강으로 먼저 보인다. 10개 빛은 뚜껑 위 10개 타격 지점을 유지하며, 각각 닿기 전에는 사라지지 않는다. 마지막 160ms에 재가속하고 14ms 간격으로 타격한다.

케이스 바닥을 기준으로 짧은 압축·감쇠 흔들림을 적용했다. 전체 화면을 덮는 충돌 섬광을 없애고 접점별 섬광·불꽃·달러 흔적을 남긴다. 먼지는 케이스 뒤로 배치했다. 하늘 낙하 시간과 개별 보상 색·순서는 유지한다.

[개별 타격 최신 시연](../../../../local-archive/gacha-videos/qa/gacha-presentation-2026-10-11/tracking/special_10_lid_strikes.mp4). 관련 테스트 24개와 정적 검사 통과. 낙하 중간부터 접촉까지 빛 사이 최소 간격 및 서로 다른 타격 지점·시차, 충돌 직전 가속을 검증했다. 이 영상 역시 420×900·15fps Flutter 출력이며 실기기 성능 측정은 아니다.

## 정면 케이스 구도

2026-10-12: 기존 Blender 모델의 카메라를 정면으로 옮기고 닫힘부터 완전 개방까지 24장을 다시 렌더링했다. 손잡이·잠금장치가 좌우 대칭으로 보이며, 뚜껑과 내부가 보이도록 약 28도 내려다본다. 이미지 크기·지면 기준점·10개 빛의 타격 위치를 실제 카메라 투영 좌표에 맞췄다. 낙하 시간·타격 시차·보상 결과는 유지했다.
